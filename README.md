# C++23 Project Template

[![License: Apache 2.0](https://img.shields.io/badge/License-Apache%202.0-blue.svg)](LICENSE)
[![C++23](https://img.shields.io/badge/C%2B%2B-23-blue.svg)](https://en.cppreference.com/w/cpp/23)

**A modern C++23 project template with module support, CMake, tests, and ready-to-use CI/CD.**

This repository is a starting point for new C++ libraries or applications. It includes best practices: Pitchfork Layout, C++23 modules, isolated tests (Catch2), static analysis (clang-tidy), automatic formatting (clang-format), and GitHub Actions.
